# Gestión de Tutelas, Acciones de Cumplimiento y PQRS (SDM)

Aplicación para gestionar las tutelas, acciones de cumplimiento y PQRS de la Secretaría Distrital de Movilidad: registro desde el buzón de Microsoft 365, reparto, escritos, devoluciones, decisiones judiciales, alertas y ANS del contrato.

## Contenido

- `Docs/Flujo proceso - sabana.xlsx`: flujo del proceso, campos por etapa, seguimiento de PQRS, indicadores ANS y volumen del plan de choque.

## Estado

En análisis y diseño. Aplicación independiente de Nodex (repositorio, base de datos y servidor propios).
